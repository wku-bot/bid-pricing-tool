# 投标价格测算网页：上传与使用步骤

这是可直接放到 GitHub Pages 的独立静态网页。初始内容都是通用演示：采购金额 1,000,000 元，公司名称为“我们公司”和“竞争对手 A/B/C/D”。请使用前填写本次项目资料。

## 先在电脑上试用

1. 解压分享 ZIP。
2. 双击 `index.html`，用较新的 Chrome、Edge 或 Safari 打开。
3. 保持联网：Excel 导入组件从固定 CDN 加载 SheetJS 0.18.5。无法联网或 CDN 被拦截时，手动测算仍可用，Excel 导入会提示组件未加载。
4. 设置项目名称、包号、采购金额，并按采购文件填写独立的最高限价。最高限价未明确时留空。
5. 选择金额或折扣率报价方式。导入 Excel 后确认工作表、表头行、公司列、报价列、单位和“我们公司”，再确认导入。
6. 修改第二轮预测。第二轮可与第一轮持平，但不能高于第一轮。只使用第二轮评分。
7. 我方第二轮输入框支持 `92.75` 等小数；加减按钮与键盘上下箭头每次调整 0.01 个百分点，滑杆同步更新金额、分数和排名。

## 网页手工上传到 GitHub

ZIP 仅供保存和传送。请先解压，再上传里面的文件，不能只上传 ZIP。

1. 登录 GitHub，点击右上角“＋”，选择 **New repository**。
2. 仓库名称可填 `bid-price-tool`，选 **Public**，点击 **Create repository**。若创建时勾选了初始化 README，也可以继续下一步。
3. 进入仓库，点击 **Add file → Upload files**。空仓库若没有此按钮，点击页面的 **uploading an existing file** 链接。
4. 将解压后的 `index.html`、`README.md`、`.nojekyll` 上传到仓库根目录。不要再套一层 `github-pages` 文件夹。
5. 页面下方填写提交说明，如“添加投标测算网页”，点击 **Commit changes**，提交到 `main` 分支。
6. 点击仓库 **Settings → Pages**。
7. 在 **Build and deployment** 下，将 **Source** 选为 **Deploy from a branch**。
8. **Branch** 选择 `main`，文件夹选择 **/ (root)**，点击 **Save**。
9. 等待部署完成后刷新 Pages 设置页。点击页面显示的 **Visit site** 或部署网址，确认能打开测算界面。
10. 将 GitHub 实际显示的网页链接发给同事。此文件包尚未发布，没有已经可访问的部署网址。

若 macOS 隐藏 `.nojekyll`，在 Finder 按 **Command + Shift + .** 显示隐藏文件后选择它。文件名应保持为 `index.html`；`.nojekyll` 是空文件。

GitHub Free 个人账号通常需要公开仓库来使用 Pages，网页也公开可访问。请以账户当前可用选项及 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages) 为准。部署方式可参考 [官方发布来源配置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。公开仓库只放本包的演示资料，不要上传实际报价 Excel、截图或真实项目附件。

## 同事使用与数据边界

每位同事在自己的浏览器填写项目和选择本机 Excel，计算在各自浏览器内完成。此工具没有服务器数据上传、账号或共享项目功能。大家访问同一网页，不代表能看到彼此填入的数据。

刷新或关闭后，当前项目数据不保证保留；请保存原始 Excel。Excel 组件的下载会访问 CDN，但工具没有将导入表格发送到服务器的业务逻辑。

## 评分与默认值

- 第一轮折扣率 ≥ 95% 时第二轮默认 92.5%；低于 95% 时默认持平，手动修改值保留。
- 金额模式以采购金额计算折扣率及第二轮金额，最高限价独立。
- 报价排名按第二轮价格从低到高，同价并列；价格分另行排名。
- 区间平均价浮动法：M≤5 不剔除；5<M≤10 去 1 低 1 高；10<M≤20 去 1 低 2 高；20<M≤30 去 2 低 3 高；M>30 去 3 低 4 高。剩余均值 A1，严格筛选 (0.85A1,1.10A1)，为空则使用剩余报价。有效均值 A2，基准=A2(1−C)。高于或等于基准扣分系数 1，低于基准为 0.5。
- 百分制分数=max(0,100−100×扣分系数×|报价−基准|÷基准)。权重可修改。
- 简单平均法使用全体第二轮平均值，双方扣分系数均为 1，C 不参与计算。
- 粘贴新评分条款不会自动改变算法；当前仅支持上述两种方法。
